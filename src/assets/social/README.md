`SocialBrandIcon.astro` renders only these local SVGs. The surrounding visible platform label supplies the accessible name, so the decorative SVG wrapper is hidden from assistive technology. No external font, CDN script or runtime icon package is used. Profile URLs remain absent until supplied by the owner.
